\subsection{Hierarchical Linear Mixed-Effects Model}
To determine statistical significance, we fitted a Hierarchical LMM regressing $\Delta_{CC}$ on Group classification (with Subject as a random intercept):
\begin{equation}
    \Delta_{CC} \sim \text{Group} + \text{Time} + (1 \mid \text{Subject})
\end{equation}

\textbf{Statistical Results:}
\begin{itemize}
    \item \textbf{Intercept (Group A Baseline):} $0.496 \pm 0.031$ ($t = 15.768$, $p < 0.001$)
    \item \textbf{Group B (Volatile) Effect:} $\beta = -0.061 \pm 0.025$ ($t = -2.401$, \textbf{$p = 0.0167$})
\end{itemize}
